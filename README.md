# Fire Emblem: Fortune's Weave · Wiki

A community wiki for *Fire Emblem: Fortune's Weave*, in English and Spanish: characters, classes, skills, mounts, items, the world map, every route and chapter, supports, blessings, guides, and a planner for your own playthrough.

It runs in the browser, on phones too, and works offline once opened.

## Run it locally

All you need is a static file server. From the repository folder:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
